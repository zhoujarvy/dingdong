# 叮咚离线部署教程（内网 Windows 7 / Windows 10）

> 适用场景：生产服务器处于**完全离线的内网**，操作系统 Windows 7 SP1 或 Windows 10，已预装 **Python 3.8**。
> 拓扑：**Nginx（80 端口，静态托管 + 反向代理）→ FastAPI/uvicorn（127.0.0.1:8000，NSSM 守护的 Windows 服务）**
>
> 在线部署（可联网服务器）请直接看 [部署说明.md](部署说明.md)。

## 0. 总览

需要准备两类东西：

| 类别 | 内容 | 来源 |
|------|------|------|
| 项目离线包 | 本仓库代码 + `deploy\offline-packages\`（21 个 wheel，已随仓库提供） | 本目录 |
| 外网机一次性下载 | Python 3.8.10 安装包、Nginx、NSSM | 见下文 |

本仓库的 `deploy\offline-packages\` 已包含全部 Python 依赖（fastapi、uvicorn、pydantic 等，均为 Python 3.8 / win_amd64 兼容版本），目标机**无需访问 pip 源**。

## 1. 外网机：一次性下载三样东西

在一台能上网的电脑上下载，U 盘拷入内网：

1. **Python 3.8.10（amd64）安装包**
   `python-3.8.10-amd64.exe`（目标机已装 3.8 可跳过；Win7 必须用 3.8，更高版本不支持 Win7）
   下载页：https://www.python.org/downloads/release/python-3810/
2. **Nginx for Windows**（zip 解压即用，无需安装）
   下载页：https://nginx.org/en/download.html（取 Stable 版，如 nginx/1.26.x）
3. **NSSM**（Windows 服务封装工具，单 exe）
   下载页：https://nssm.cc/download（取 nssm-2.24 win64，解压取 `nssm.exe`）

## 2. 拷贝到内网服务器

建议目录布局（后文命令均以此为准）：

```
D:\dingdong\            项目代码（server / web / client / docs / deploy）
D:\dingdong\deploy\offline-packages\   Python 离线依赖（21 个 .whl）
D:\dingdong\deploy\nssm.exe            NSSM（解压后放入）
C:\nginx\               Nginx（zip 解压）
```

> 客户端安装包 `DingDongSetup.exe` 已在 `server\downloads\`（.NET 6 自包含，目标机免装运行时），
> 无需再为客户端准备任何环境。

## 3. 安装 Python（目标机没有 3.8 时）

双击 `python-3.8.10-amd64.exe`，勾选 **Add Python to PATH**，自定义安装时勾选 pip。

## 4. 创建虚拟环境 + 离线安装依赖

```bat
cd /d D:\dingdong\server
py -3.8 -m venv venv

:: 关键：--no-index 禁止联网，--find-links 指向离线包目录
venv\Scripts\pip install --no-index --find-links ..\deploy\offline-packages -r requirements.txt

:: 修改管理密码（务必）
notepad config.json

:: 试运行确认正常（Ctrl+C 退出）
venv\Scripts\python run.py
```

浏览器访问 `http://127.0.0.1:8000/` 能看到官网即成功。

## 5. NSSM：注册 Windows 服务

确保 `nssm.exe` 已放在 `D:\dingdong\deploy\`。

```bat
cd /d D:\dingdong\deploy
service.bat install     :: 安装并启动服务（开机自启）
```

验证：

```bat
nssm status DingDongServer
curl http://127.0.0.1:8000/api/download/info
```

要点（脚本已内置）：
- 工作目录 `D:\dingdong\server`，数据库 `dingdong.db` 落在该目录
- 日志输出到 `server\logs\`，单文件 5MB 自动轮转
- 崩溃自动拉起、随系统自启动
- 日常管理：`service.bat restart`（更新代码后）/ `service.bat uninstall`

## 6. Nginx：静态托管 + 反向代理

1. 将外网机下载的 nginx zip 解压到 `C:\nginx`。
2. 把 `deploy\nginx-dingdong.conf` 复制为 `C:\nginx\conf\conf.d\dingdong.conf`，
   并确认 `C:\nginx\conf\nginx.conf` 的 `http{}` 中有 `include conf.d/*.conf;`。
3. 按需修改 conf 中的 `server_name`（默认 `_`，内网 IP 访问无需改）。
4. 启动：

```bat
cd /d C:\nginx
start nginx
nginx -s reload    :: 改配置后重载
```

5. 防火墙放行 80 端口（客户端与浏览器都走这里）：

```powershell
netsh advfirewall firewall add rule name="DingDong 80" dir=in action=allow protocol=TCP localport=80
```

反向代理已包含 WebSocket 升级头与 300 秒读超时（大于客户端 30 秒心跳周期），`/ws` 长连接可稳定穿透。

## 7. 客户端分发与注册

1. 内网任意电脑浏览器打开 `http://服务器IP/`，下载 `DingDongSetup.exe` 安装
   （当前用户模式，无需管理员权限，.NET 运行时已内嵌，Win7 SP1 / Win10 均可直接安装）。
2. 首次运行填写服务器地址 `http://服务器IP`（80 端口，无需带 :8000）与终端名称，注册获得 6 位终端编码。

## 8. 升级流程（离线）

```bat
:: 1. 外网机/开发机准备好新版代码（如需前端改动，先 cd web && npm run build 产物随代码携带）
:: 2. 覆盖 D:\dingdong\ 对应目录（注意保留 server\config.json 与 server\dingdong.db）
:: 3. 依赖有新增时：pip install --no-index --find-links ..\deploy\offline-packages -r requirements.txt
:: 4. 重启服务
cd /d D:\dingdong\deploy && service.bat restart
:: 5. 新版客户端：开发机运行 client\make_installer.bat，把整个 server\downloads\ 拷贝覆盖
```

## 9. 数据备份

定期备份 `server\dingdong.db`（建议先 `service.bat restart` 前停服务，或使用 `sqlite3 .backup`）。
WAL 模式下同时备份 `dingdong.db-shm`、`dingdong.db-wal` 三个文件亦可。

## 10. 常见问题

| 现象 | 处理 |
|------|------|
| pip 离线安装报 "No matching distribution" | 确认用的是 Python 3.8 的 venv（wheel 文件名含 cp38）；`venv\Scripts\python --version` 检查 |
| 服务起不来 | `nssm dump DingDongServer` 看配置；查 `server\logs\error.log`；确认 venv 路径正确 |
| WS 连不上 | Nginx 是否加载了带 Upgrade 头的配置；`proxy_read_timeout` 是否过短 |
| 官网能开但下载 404 | 检查 `server\downloads\DingDongSetup.exe` 是否存在 |
| 8000 被占用 | 改 `config.json` 的 `port`，同时改 Nginx 反代目标端口 |
| Win7 上 Nginx 起不来 | 用 nginx 1.24/1.26 等仍支持 Win7 的版本，并安装 VC++ 运行库 |
